## 함정

- 미리보기는 **홈 → 총무 타일로 들어가야** `OnVisible`이 돈다
- 미리보기가 총무 화면에서 바로 열린 직후 좌표 클릭으로 "부서 실사 개시"가 눌린 적이 있다(이미 헤더가 있어 생성 0건). 시작 직후 클릭 주의
- Studio에서 Ctrl+S가 트리 검색창에 "s"로 입력되는 경우가 있다 → 툴바 저장 아이콘
- **조직 필터는 자산 보유부서 텍스트 = 사업부 이름일 때만 잡힌다.** 조직도 밖 부서명 자산은 부서·팀을 하나라도 체크하면 빠진다
  ("자산이 정확히 안 나온다"는 9/30 사용자 제보의 원인. 테스트 자산을 사업부 이름으로 재배정해 해결)
- KPI "제출 부서 N / M"의 M은 실사 헤더 수가 아니라 **자산 보유부서 종류 수**다
- Studio 미리보기는 데이터 원본을 캐시한다 — API로 바꾼 값은 홈 → 타일로 다시 들어가야 보인다
